📊 Netflix Dataset — Exploratory Data Analysis (EDA)

🔹Project Overview

As part of my CodeAlpha Data Analyst Internship, I worked on an Exploratory Data Analysis (EDA) project using the Netflix Titles dataset. 
The aim was to uncover insights into content distribution, genre preferences, production countries, and release trends over time.

🔹 Dataset:
The dataset (netflix_titles.csv) contains 8,807 rows and 12 features, including:

 ● show_id (unique identifier)

 ● type (Movie / TV Show)

 ● title, director, cast

 ● country, date_added, release_year

 ● rating, duration, listed_in (genres), description

🔹 Process & Analysis:

 ● Data Cleaning: Reviewed structure, treated missing values (e.g., country, director, cast), and removed duplicates.

🔹Exploratory Analysis:

  ● Tracked release year trends across decades.

  ● Compared Movies vs. TV Shows distribution.

 ● Identified top content-producing countries.

 ● Highlighted most frequent genres.

🔹 Key Insights:

 ✔ The US and India emerged as leading contributors.

 ✔ International Movies, Dramas, and Comedies are the most common genres.

 ✔ Netflix’s content expansion peaked around 2018–2019, reflecting its global push.

🔹 Tools & Libraries:

 ● Python
 
 ● Pandas (data wrangling & preprocessing)
 
 ● Matplotlib & Seaborn (visualization)

✨ Result: A cleaner dataset and clear patterns that showcase how Netflix has evolved into a diverse, globally inclusive streaming platform.
